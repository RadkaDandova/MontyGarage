# Monty Garage

1. Otevřete `index.html` v rozbalené složce.
2. Na GitHub nahrajte celý obsah této složky.
3. V Settings → Pages nastavte `main` a `/ (root)`.
4. Poptávkový formulář používá `mailto:` a otevře e-mailovou aplikaci návštěvníka.
5. Sekci Naše práce lze později doplnit vlastními fotografiemi.
